 Automation Task
This project is an automated UI testing suite developed using Selenium WebDriver with Java and TestNG. It covers essential e-commerce workflows including Login, Product Page, Cart Page, and the Checkout Process.

📖 Project Overview
This Selenium automation project simulates a typical user journey on an e-commerce website, performing actions like logging in, browsing products, adding items to the cart, and completing the checkout process.

⚙️ Tech Stack
Language: Java

Automation Framework: Selenium WebDriver

Test Framework: TestNG

Build Tool: Maven (if applicable — if not, remove this line)

Browser Driver: ChromeDriver (or other)

✅ Test Scenarios
The suite currently covers the following test cases:

Login Page Test

Product Page Test

Cart Page Test

Checkout Process Test

-Setup Instructions
1-Clone the repository:
bash
git clone https://github.com/Abdelrahmanibrahem22/Automation_Task.git
2-Install Dependencies
-Install Java JDK 8+
-Install TestNG plugin in your IDE (e.g., IntelliJ or Eclipse)
-Install ChromeDriver and set its path in your project
▶️ How to Run Tests
Via TestNG Suite XML
-Open testng.xml
-Right-click and select Run 'testng.xml'
